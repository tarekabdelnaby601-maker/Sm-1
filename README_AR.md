# SmPlan Premium 2.0 — مشروع Android

هذا المشروع يحوّل ملف SmPlan HTML الأصلي إلى تطبيق Android باستخدام WebView، مع الاحتفاظ بمفاتيح التخزين القديمة (`smplan_tasks_v40` و`smplan_cats_v40` و`smplan_habits_v40` و`smplan_journal_v40` و`smplan_xp`).

## ما الذي أُضيف؟
- واجهة Premium فاتحة افتراضيًا مع ثيم أخضر، داكن، أزرق، بنفسجي، ووردي.
- لوحة تحكم وإحصائيات للمهام والعادات والأولويات.
- مهام فرعية متداخلة بعدة مستويات، مع استمرار دعم المهام الفرعية القديمة.
- تسجيل إنجاز العادة مرة واحدة يوميًا وحساب سلسلة الاستمرارية.
- تاريخ استحقاق ووقت تذكير لكل مهمة جديدة.
- إشعارات Android مجدولة عبر AlarmManager، مع طلب إذن الإشعارات على Android 13 وما بعده.
- نسخ احتياطي JSON واستعادة متوافقة مع النسخ القديمة.
- مزامنة سحابية اختيارية عبر Firebase Authentication (Email/Password) وCloud Firestore.
- استمرار العمل محليًا دون إنترنت؛ الاتصال مطلوب فقط لخطوط Google وبعض الموارد الخارجية ومزامنة Firebase.

## مهم قبل استبدال النسخة القديمة (حماية بياناتك)
1. افتح نسخة SmPlan القديمة التي تحتوي على مهامك.
2. من القائمة اختر **تصدير ملف JSON** واحفظ ملف النسخة الاحتياطية في الهاتف.
3. بعد تثبيت APK الجديد افتح القائمة > المزامنة السحابية والنسخ الاحتياطي > استعادة نسخة JSON، واختر الملف القديم.

هذه الخطوة مهمة إذا كانت النسخة القديمة تعمل داخل متصفح أو WebView مختلف؛ Android يعزل `localStorage` حسب أصل التطبيق، لذلك لا يمكن ضمان نقل قاعدة المتصفح تلقائيًا بين أصلين مختلفين. مفاتيح البيانات القديمة نفسها مدعومة داخل النسخة الجديدة، والاستيراد يحافظ على المهام والعادات والقوائم والملاحظات ورصيد XP.

## بناء APK من GitHub باستخدام الهاتف
1. أنشئ مستودع GitHub جديدًا وارفع محتويات هذا المجلد إليه، مع الحفاظ على مجلد `.github`.
2. افتح تبويب **Actions** في المستودع.
3. شغّل **Build SmPlan APK** عبر Run workflow، أو ادفع commit إلى فرع `main`.
4. بعد نجاح البناء افتح نتيجة التشغيل، ثم نزّل Artifact باسم `SmPlan-Premium-debug-apk`.
5. فك ضغط الملف وثبّت `app-debug.apk` على هاتف Android. قد يطلب الهاتف السماح بالتثبيت من مصدر خارجي.

## تفعيل المزامنة السحابية (مرة واحدة)
1. أنشئ مشروعًا في Firebase Console.
2. أضف تطبيق Web إلى المشروع، وانسخ إعدادات Firebase.
3. افتح `app/src/main/assets/firebase-config.js` واستبدل القيم `PASTE_...` بالقيم الحقيقية.
4. من Firebase Authentication فعّل **Email/Password**.
5. أنشئ قاعدة بيانات Cloud Firestore.
6. انسخ محتوى `firestore.rules` إلى تبويب Rules في Firestore ثم انشر القواعد.
7. أعد بناء APK وارفعه إلى هاتفك.
8. من داخل التطبيق افتح القائمة > المزامنة السحابية، أنشئ حسابًا أو سجّل الدخول. استخدم الحساب نفسه على الأجهزة الأخرى.

**تنبيه أمني:** Firebase Web API key الموجود في تطبيقات الويب ليس سرًا بحد ذاته؛ الحماية الفعلية هنا تعتمد على Firebase Authentication وقواعد Firestore المقيدة بمعرّف المستخدم. لا تضع Service Account أو مفاتيح Admin داخل التطبيق.

## ملاحظات مهمة
- أول تسجيل دخول على جهاز به بيانات محلية: إذا وُجدت بيانات سابقة على السحابة سيطلب التطبيق تأكيد استبدال بيانات الجهاز. اختر إلغاء للاحتفاظ بالمحلي، ثم استخدم «مزامنة الآن» لرفع المحلي.
- المزامنة تلقائية بعد التغييرات عند تسجيل الدخول، مع تأخير قصير لتجميع عمليات الحفظ، ويمكن تنفيذها يدويًا.
- الإحصاء الأسبوعي لتاريخ الإنجاز يبدأ من الإصدار الجديد؛ المهام القديمة التي لا تملك `completedAt` لا يمكن استنتاج تاريخ إنجازها بأثر رجعي.
- الإشعار المجدول يعتمد على وقت الهاتف وإذن الإشعارات. وضع توفير البطارية الشديد لدى بعض الشركات قد يؤخر التنبيه.
- بعض العناصر الخارجية (خط Cairo، Material Symbols، Firebase، confetti، وخلفيات Unsplash) تحتاج إنترنت. الوظائف الأساسية والبيانات المحلية لا تحتاج اتصالًا.
- هذا مشروع APK Debug للتجربة والاستخدام الشخصي. للنشر العام يلزم إعداد توقيع Release ومراجعة سياسة الخصوصية وإعدادات Firebase.
